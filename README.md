本程序是为了解决solid works2018一键安装版原卸载程序（双击静默卸载.vbs）出现的卸载不干净问题而制作的程序


功能：1、能够彻底删除solid works2018一键安装版
             2、能够解决因为原程序造成的solid works2018一键安装版卸载不干净问题


使用方法：1、将本程序（双击静默卸载（修复版）.vbs）复制到原卸载程序（双击静默卸载.vbs）同级路径下
                       2、双击运行本程序（双击静默卸载（修复版）.vbs）等待卸载完成即可
                       
                       卸载残留问题同样方法适用
